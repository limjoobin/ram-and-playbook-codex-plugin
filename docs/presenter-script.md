# Five-minute presentation

Use two Macs, two Claude accounts, and the fictional Northstar Retail namespace.
Disclose that the six baseline memories were seeded beforehand.

1. On the teammate's Mac, launch `~/.local/bin/redis-memory-reader`. Ask it to
   prepare the Northstar pilot plan with region, duration, participants, data
   constraints, and success criteria. Show the returned Redis memory IDs.
2. On Hillary's Mac, launch `~/.local/bin/redis-memory-editor`. Ask it to find
   the region record and update that same ID from Singapore to Tokyo.
3. Wait for `saved_and_searchable`. On the teammate's still-running Reader,
   repeat the question. Show Tokyo, the same memory ID, and the newer timestamp.
4. Ask Reader to change the duration. Show that its MCP server has no write tool.

If RAM is unavailable, state that live retrieval could not be verified. Do not
substitute facts from chat history or describe a simulated response as live.
